KIVA ÇİKOLATA — KURUMSAL ÜRÜN KATALOĞU V7

GitHub Pages yükleme:
1. ZIP dosyasını bilgisayarınızda açın.
2. ZIP'in KENDİSİNİ değil, içindeki index.html, styles.css, script.js,
   favicon ve manifest dosyaları ile assets klasörünü depo ana dizinine yükleyin.
3. GitHub / Settings / Pages / Deploy from a branch / main / (root) seçin.
4. Bir önceki sürümün eski dosyalarını temizleyin. Güncelleme sonrası Ctrl+Shift+R.

İçerik: 8 ürün, filtreli katalog, 3 ürünlü hero, detay dialogları,
responsive menü, özel koleksiyonlar, Web3Forms iletişim formu.

NOTLAR:
- Sitede fiyat, ödeme, sepet veya online satış bulunmaz.
- İletişim formu canlıda test edilmelidir.
- Tasarımcının Instagram/LinkedIn hesapları resmi KIVA hesabı olarak sunulmaz.
- Domain için alan adı / DNS kaydı ayrıca yönetilmelidir.
- Fiziksel ürünlerin etiket bilgilerini resmi ürün verileriyle doğrulayın.
- Sosyal paylaşım önizlemesi için yayın sonrası og:image mutlak URL olabilir.
- Bu site, hız ve mobil düzen kontrolü yapılmış statik bir sitedir;
  gerçek cihazlar ve canlı ağ koşullarında ayrıca test önerilir.
